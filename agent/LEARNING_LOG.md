## A2. ReAct graph by hand
- (Nov 9) Predictions:
  - Why tool_call_id: are the tools called asynchronously? if so, then it's hard to know which message is tied to a tool due to different latencies.
    - *Feedback (Claude): Good instinct.   - No reducer on messages: memory would be overwritten and the agent couldn't do anything useful
    - *Feedback (Claude): Right. Concretely: after the first agent turn, messages would be just [reply]; the question is gone, and after the tool node only the tool results remain.
